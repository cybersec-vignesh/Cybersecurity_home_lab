# SOC Detection Lab – Splunk

## Objective

Simulate attacker activity and detect it using Splunk SIEM.

## Lab Setup

Attacker Machine: Parrot OS
Victim Machine: Ubuntu Server
Monitoring: Splunk SIEM

## Attack Simulation

Example attack performed:

Nmap Scan

Command used:

nmap -sS <target-ip>

## Detection

Splunk was used to analyze logs and detect scanning activity.

## Skills Learned

* Threat detection
* SIEM monitoring
* Log analysis
